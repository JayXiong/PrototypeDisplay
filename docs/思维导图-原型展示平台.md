# 原型展示平台

## 技术架构
### 后端：Python（FastAPI）
#### 提供 REST API + 原型静态文件服务
### 数据库：MySQL
#### 项目数据 / 访问日志
### 前端：Vue 3
#### 管理后台单页应用
### 部署
#### 单机部署，Docker 可选

## 用户认证（单管理员）
### 账户
#### 仅一个管理员账号（配置文件初始化）
### 登录
#### 账号密码登录
#### JWT Token 鉴权
#### Token 过期自动跳转登录页
### 安全
#### 密码哈希存储
#### 可修改密码

## 项目管理
### 项目属性
#### 项目名称
#### 备注
#### 状态（启用 / 禁用）
#### 访问链接（自动生成 slug 短链）
### 新建项目
#### 填写名称、备注
#### 上传原型文件
##### 单个 HTML 文件
##### 或 ZIP 包（含 index.html + 静态资源 css/js/img）
### 更新原型
#### 重新上传覆盖
#### 保留历史版本（可选）
### 禁用 / 启用原型
#### 禁用后访客看到提示页
#### 一键恢复启用
### 删除项目
#### 删除原型文件与统计数据（二次确认）

## 原型访问
### 访客链接
#### 格式：http(s)://域名/p/{slug}
#### 无需登录即可访问
### 服务方式
#### 后端路由返回原型文件
#### 中间件记录访问日志
### 异常状态
#### 原型不存在 → 404 页
#### 原型已禁用 → 提示页

## 访问统计
### 数据采集
#### 记录：项目 ID、IP、UA、访问时间
### 聚合维度
#### 按小时统计
#### 按天统计
### 统计视图
#### 全部项目总览
##### 访问总量 / 今日访问
##### 访问趋势折线图（切换 小时 / 天）
#### 单项目详情
##### 该项目趋势图
##### 最近访问记录列表
### 排行
#### 按访问量排序的项目列表

## 数据库设计（MySQL）
### user 表
#### id / username / password_hash
### project 表
#### id / name / slug / remark / status / created_at / updated_at
### visit_log 表
#### id / project_id / ip / user_agent / visited_at
#### 索引：project_id + visited_at

## 页面结构（Vue 管理端）
### 登录页
### 项目列表页（首页）
#### 搜索 / 状态筛选
#### 复制访问链接
### 项目编辑页
#### 上传 / 更新原型
#### 编辑名称、备注
### 统计页
#### 总览图表
#### 单项目统计

## 非功能需求
### 大文件上传限制（如 50MB）
### 文件存储目录与备份
### 访问日志定期归档（可选）
