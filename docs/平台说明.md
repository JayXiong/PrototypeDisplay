# 原型展示平台（PrototypeDisplay）

![原型展示平台](assets/platform-cover-600x400.png)

**原型展示平台** 是一款轻量级的 HTML 原型托管与访问统计工具，把「传文件给同事看原型」变成「发一个链接」，谁看了、什么时候看的、看得多不多，一目了然。

## 主要功能

- 一键托管分享：上传单个 HTML 或含 `index.html` 的 ZIP 包（带 CSS/JS/图片的复杂原型照常运行），自动生成 `https://域名/p/xxxx/` 短链，访客免登录直接看
- 项目管理：项目名称、备注、启用/禁用状态一应俱全；更新原型即时生效（链接不变、内容替换），禁用后访客看到「原型已禁用」提示页，可随时一键恢复
- 访问统计：自动记录每次页面访问（项目 / IP / 浏览器 / 时间），支持按小时和按天两个粒度看趋势折线图，全平台总览、单项目详情、项目访问量排行一屏掌握
- 单管理员模式：一个账号管理所有项目，JWT 登录鉴权，支持随时修改密码
- 极简部署：Docker 一键启动（MySQL + 后端 + 前端自动构建打包一体），支持宝塔反向代理绑定域名与免费 HTTPS

## 使用步骤

1. 浏览器打开管理后台，用管理员账号登录
2. 点「新建项目」，填写项目名称和备注，上传 HTML 文件或 ZIP 原型包（≤50MB）
3. 在项目列表复制生成的访问链接，发给开发、业务或客户
4. 原型有修改时点「编辑」重新上传，链接与访问数据保持不变；需要下线时拨动「禁用」开关
5. 到「访问统计」页查看累计/今日访问量、按小时或按天的趋势图，以及哪个项目最受欢迎

## 适用场景

- 产品经理 / 设计师发布原型给开发与业务评审，告别微信传文件和「最新版是哪个」的困惑
- 原型多版本迭代统一管理：链接始终不变，内容始终最新
- 汇报与复盘有据可依：用访问量数据证明原型被真实查看过，看清团队关注点在哪
- 外部演示（客户、合作方）：发一个干净短链，不想给看了随时禁用
