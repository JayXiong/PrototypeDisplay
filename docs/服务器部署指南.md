# 服务器部署指南（保姆级）

> 目标：把平台部署到公司 Linux 服务器，同事通过浏览器长期访问。
> 全程大约 15~30 分钟（主要耗时在下载 Docker 镜像）。

## 你需要准备

1. 一台公司 Linux 服务器（CentOS 7+ / Ubuntu 均可），并且有 SSH 登录账号
2. 一个 SSH 连接工具：Windows 自带的 `powershell` 即可（用 `ssh` 命令），或 XShell / FinalShell
3. 服务器能访问外网（或公司内部有 Docker 镜像源）

## 第一步：上传部署包

把 `原型展示平台-部署包.zip` 上传到服务器（任选一种）：

- **FinalShell / XShell**：直接拖拽文件到服务器文件面板
- **scp 命令**（在 Windows PowerShell 里执行）：

```powershell
scp .\原型展示平台-部署包.zip 用户名@服务器IP:/home/用户名/
```

然后在服务器上解压：

```bash
cd /home/用户名
unzip 原型展示平台-部署包.zip
cd PrototypeDisplay
```

> 没有 unzip 命令？执行 `yum install -y unzip`（CentOS）或 `apt install -y unzip`（Ubuntu）

## 第二步：安装 Docker（已装可跳过）

在服务器上执行（需要 root 或 sudo 权限）：

```bash
# 官方一键安装脚本（国内网络可用阿里云版）
curl -fsSL https://get.docker.com | bash -s docker --mirror Aliyun

# 启动并设置开机自启
sudo systemctl start docker
sudo systemctl enable docker

# 验证
docker --version
```

**配置国内镜像加速**（公司网络拉取 Docker Hub 慢/失败时必须做）：

```bash
sudo mkdir -p /etc/docker
sudo tee /etc/docker/daemon.json <<-'EOF'
{
  "registry-mirrors": [
    "https://docker.m.daocloud.io",
    "https://dockerproxy.com"
  ]
}
EOF
sudo systemctl restart docker
```

> 如果公司有内部镜像仓库地址，优先填公司的。镜像加速地址可能随时间失效，搜索"Docker 镜像加速 可用"获取最新地址。

## 第三步：配置并启动

```bash
cd PrototypeDisplay
chmod +x deploy.sh
./deploy.sh
```

- 首次运行会生成 `.env` 配置文件，按提示用 `vi .env` 修改：
  - `ADMIN_PASSWORD`：你的管理员登录密码（**必改**）
  - `SECRET_KEY`：随便敲一长串字母数字（**必改**）
  - `MYSQL_ROOT_PASSWORD`：容器内数据库密码（建议改）
  - `APP_PORT`：对外端口，默认 `8080`
- 改完再执行一次 `./deploy.sh`，开始构建（首次约 3~10 分钟）

## 第四步：开放防火墙端口

```bash
# firewalld（CentOS 常见）
sudo firewall-cmd --permanent --add-port=8080/tcp && sudo firewall-cmd --reload

# ufw（Ubuntu 常见）
sudo ufw allow 8080/tcp
```

> 云服务器（阿里云/腾讯云等）还需要在控制台的「安全组」里放行 8080 端口。

## 第五步：验证

在你自己电脑的浏览器打开：

```
http://服务器IP:8080
```

用 `.env` 里配置的账号登录（用户名默认 `admin`），创建一个项目上传原型，复制生成的链接发给同事试试。

## 日常运维命令（在部署目录执行）

| 操作 | 命令 |
|------|------|
| 查看运行状态 | `docker compose ps` |
| 看应用日志 | `docker compose logs -f app`（Ctrl+C 退出） |
| 重启服务 | `docker compose restart` |
| 停止服务 | `docker compose down` |
| 更新代码后重新部署 | `docker compose up -d --build` |
| 备份数据库 | `docker compose exec db sh -c 'mysqldump -uroot -p$MYSQL_ROOT_PASSWORD proto_display' > backup.sql` |
| 备份原型文件 | `docker run --rm -v proto-display_uploads_data:/data -v $(pwd):/bak alpine tar czf /bak/uploads_backup.tar.gz /data` |

## 常见问题

| 现象 | 处理 |
|------|------|
| `docker compose` 命令不存在 | 老版本 Docker 用 `docker-compose`（中间有横线），或升级 Docker |
| 拉取 mysql 镜像超时 | 配置上面的国内镜像加速；或找网管要公司内部镜像源 |
| 端口 8080 被占用 | `.env` 里改 `APP_PORT=9090`，重新 `./deploy.sh` |
| 页面打不开 | 依次检查：`docker compose ps` 是否两个容器都 Up → 防火墙/安全组是否放行 → 云服务器安全组规则 |
| 忘记管理员密码 | 见 README「常见问题」一节重置 |

## 数据都在哪

- MySQL 数据 → Docker 卷 `proto-display_db_data`（删容器不丢数据）
- 上传的原型文件 → Docker 卷 `proto-display_uploads_data`
- 定期用上面的备份命令导出即可
